# 🔭 BeginnerStargazer.com

Honest telescope reviews and stargazing guides for people just starting out.
Built with Astro, Tailwind CSS, and deployed on Vercel.

---

## Tech Stack

| Layer | Tool |
|---|---|
| Framework | [Astro](https://astro.build) v4 |
| Styling | [Tailwind CSS](https://tailwindcss.com) v3 |
| Interactive components | React 18 (islands) |
| Content | Markdown / MDX files |
| Hosting | [Vercel](https://vercel.com) |
| Version control | GitHub |

---

## Getting Started

### Prerequisites
- Node.js 18+ 
- npm or pnpm

### 1. Clone and install

```bash
git clone https://github.com/yourusername/beginnerstargazer.git
cd beginnerstargazer
npm install
```

### 2. Run the dev server

```bash
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser.

### 3. Build for production

```bash
npm run build
npm run preview   # preview the build locally
```

## Writing Content

### Adding a new review

Create a file at `content/reviews/your-telescope-name.md`:

```markdown
---
title: "Telescope Name Review: Subtitle Here"
description: "160 chars max for SEO"
pubDate: 2026-05-15
productName: "Full Product Name"
productType: "telescope"   # telescope|mount|eyepiece|accessory|camera|binoculars
brand: "Brand Name"
price: 299
priceRange: "mid-range"    # budget|mid-range|premium
rating: 4.5
verdict: "recommended"     # recommended|good-value|avoid|best-in-class
affiliateUrl: "https://amazon.com/dp/YOURLINK"
affiliateStore: "Amazon"
whoIsItFor: "Who this telescope suits"
whoShouldSkip: "Who should look elsewhere"
bestAlternative: "Alternative product name"
pros:
  - "Pro point one"
  - "Pro point two"
cons:
  - "Con point one"
specs:
  aperture: "130mm"
  focalLength: "650mm"
  mount: "Alt-Az"
image:
  src: "/images/reviews/your-image.jpg"
  alt: "Alt text for image"
---

Your review content in Markdown here...
```

### Adding a guide or how-to

Create a file at `content/posts/your-guide-name.md`:

```markdown
---
title: "Guide Title"
description: "160 chars max"
pubDate: 2026-05-15
category: "how-to"   # buying-guide|how-to|what-can-you-see|stargazing-guide|comparison|worth-it
tags: ["tag1", "tag2"]
featured: true
readingTime: 8
---

Guide content here...
```

## Deploying to Vercel

### First deploy

1. Push your repo to GitHub
2. Go to [vercel.com](https://vercel.com) → New Project
3. Import your GitHub repo
4. Vercel auto-detects Astro — click Deploy
5. Add your custom domain `beginnerstargazer.com` in Settings → Domains

### Subsequent deploys

```bash
git add .
git commit -m "Add new review: Telescope Name"
git push
```

Vercel automatically builds and deploys on every push to `main`. Done.

## Affiliate Link Management

Affiliate links live directly in each review's frontmatter (`affiliateUrl`).
The `ProductBox` component renders them with proper `rel="noopener noreferrer nofollow"`.

To update a link sitewide for a product, update it once in the `.md` file.

## SEO

- **Review schema** (star ratings in Google): automatically generated by `Review.astro`
- **Article schema**: automatically generated by `Article.astro`
- **Sitemap**: auto-generated by `@astrojs/sitemap` at `/sitemap-index.xml`
- **Canonical URLs**: set automatically in `Base.astro`
- **Meta descriptions**: set via `description` frontmatter field (keep under 160 chars)

## Switching Platforms Later

If you outgrow this stack:

- **→ Ghost**: Export your Markdown files. Ghost has an official importer.
- **→ WordPress**: Use a Markdown importer plugin (WP Markdown Importer).
- **→ Webflow**: Manually migrate content via Webflow CMS collections.

Your content is just Markdown files — it's portable to any platform.
